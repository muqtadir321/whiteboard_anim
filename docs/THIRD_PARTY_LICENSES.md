# Third-party licences

Best-effort register, checked 2026-10-22 against package metadata and model cards. It is not legal
advice. `commercial_status`: **approved** (licence allows commercial use of the output), **restricted**
(non-commercial or terms limit use: off by default), **unknown** (not established: off by default
where it is a model, flagged where it is content). Code and model weights are listed separately.

## Data and content sources

| Source | Terms | commercial_status |
|---|---|---|
| U.S. federal agency pages (sec.gov, census.gov, bls.gov …) | public domain, 17 U.S.C. 105 | approved (ledger default) |
| FRED (fred.stlouisfed.org) | https://fred.stlouisfed.org/legal/ (some series are third-party copyrighted) | unknown: check the series |

| Yahoo Finance | no public API; terms restrict automated access | restricted: links only, never fetched |
| Bing News RSS | feed notice: personal, non-commercial use only | restricted: off by default |
| Google News RSS | robots.txt disallows `/rss` for crawlers | restricted: off by default in the research workflow (the older Prepare Topic workflow still uses it) |
| News articles, screenshots, quotes, logos | owned by publishers | unknown: shown for commentary; never "cleared" automatically |

`reports/asset_licenses.json` (classic `run`) and `build_info.json` (`render`) record what a run actually
used. A render is marked commercially cleared only when no voice/timing model is restricted or unknown
and every source shown on screen is "approved", which in practice means it is rarely cleared. That is
deliberate: a person must decide.
