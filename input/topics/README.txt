Topic folders for explainer videos (one folder per video), written by the
"Prepare Topic (explainer video)" workflow:

  english.txt, roman_urdu.txt   draft scripts with visual tags; review and edit them
  audio/                        optional voice-overs (english.mp3, roman_urdu.mp3)
  evidence/                     screenshots, chart data, logos and manifest.json
  notes.md                      what to check, quotable sentences, chart values
  topic.yaml                    topic, sources and notices

Render one with "Generate Whiteboard Video" and topic_dir = input/topics/<folder>.
